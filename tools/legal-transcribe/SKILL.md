# 녹음파일 병렬 받아쓰기

## 원칙

- **녹음은 이 컴퓨터 밖으로 보내지 않는다.** 외부 받아쓰기 서비스(클로바노트 등)나 외부 API를 쓰지 않는다. 처음 설치할 때 받아쓰기 모델 파일만 내려받는다.
- 매번 Whisper를 새로 깔거나 한 파일씩 순서대로 돌리지 않는다. 아래 `scripts/transcribe.py` 하나로 처리한다.
- 결과는 자동 받아쓰기다. 서면에 인용할 부분은 변호사가 원음과 대조해야 한다는 점을 결과 보고 때 한 줄로 알린다.

## STEP 0. 설치 확인 (컴퓨터당 한 번)

```bash
~/.legal-transcribe-venv/bin/python <스킬폴더>/scripts/transcribe.py --check
```

- 실행되면 STEP 1로 간다.
- 없으면 설치한다. 맥·리눅스: `bash <스킬폴더>/scripts/setup.sh`, 윈도: `powershell -ExecutionPolicy Bypass -File <스킬폴더>\scripts\setup.ps1`
- 애플 실리콘 맥(M1~M4)은 mlx-whisper(GPU 사용), 그 밖에는 faster-whisper가 자동으로 선택된다. 둘 다 원조 Whisper보다 몇 배 빠르다.
- 윈도에서는 파이썬 경로가 `~\.legal-transcribe-venv\Scripts\python.exe`다.

## STEP 1. 변환 실행

녹음파일 여러 개 또는 폴더를 **한 번에** 넘긴다. 파일마다 따로 실행하면 병렬 처리 효과가 없다.

```bash
~/.legal-transcribe-venv/bin/python <스킬폴더>/scripts/transcribe.py \
  <파일1> <파일2> <폴더> --out-dir <결과폴더> --prompt "<용어 힌트>"
```

- `--prompt`: 사건에 나오는 고유명사·전문용어를 쉼표로 넣으면 받아쓰기 정확도가 올라간다(예: "근저당, 가압류, 역삼로, 대표이사"). 의뢰인 실명은 넣지 않아도 된다. 넣더라도 이 컴퓨터 안에서만 쓰인다.
- `--workers N`: 동시 작업자 수. 기본값은 CPU 코어 수와 메모리를 보고 자동으로 정한다. 다른 작업과 같이 돌려서 컴퓨터가 버벅이면 낮춘다.
- `--chunk-min`: 조각 길이(분, 기본 8). 보통 바꿀 필요 없다.
- `--model`: 기본 `large-v3-turbo`. 녹음 품질이 나빠 오류가 많으면 `large-v3`(느리지만 정확), 급하면 `small`.
- 1시간이 넘는 분량이면 백그라운드로 실행하고, 진행 상황(stderr의 `[변환] 3/12 ...` 줄)을 보며 기다린다.

### 속도를 내는 장치 (스크립트에 이미 들어 있음)

1. 긴 녹음을 무음 지점에서 8분 안팎 조각으로 잘라 여러 작업자가 동시에 처리한다. 말 중간에서 자르지 않는다.
2. 여러 파일의 조각을 한 대기열에 넣고 긴 조각부터 처리해 작업자가 노는 시간을 줄인다.
3. 조각 안에서도 발화 구간을 묶어 한꺼번에 계산(묶음 추론)하고, 무음 구간은 건너뛴다.
4. 조각별 결과를 `~/.cache/legal-transcribe`에 저장한다. 중간에 끊겨도 다시 실행하면 끝난 조각은 건너뛰고, 같은 녹음을 다른 스킬에서 다시 쓰면 즉시 결과를 돌려준다(파일 내용 해시로 식별하므로 파일명이 바뀌어도 인식).

## STEP 2. 결과 확인과 넘기기

결과 폴더에 파일마다 두 개가 생긴다.

- `<파일명>.녹취록.txt`: 첫머리에 원본 파일명, 녹음 길이, 원본 SHA-256 해시, 변환 엔진이 적히고, 이어서 `[00:12:34] 발언` 형식으로 이어진다.
- `<파일명>.녹취록.json`: 구간별 시작·끝 시각(초). 특정 발언 위치를 다시 찾을 때 쓴다.

변환 후에는 원래 요청받은 작업(사건 분석, 증거 정리, 서면 작성 등)으로 돌아가 `.녹취록.txt`를 재료로 쓴다.

## 녹취록을 인용할 때

- 녹취 내용을 사실로 적을 때는 문장마다 파일명과 시각을 붙인다. 예: 피고가 계약 해지 의사를 밝혔다. [통화녹음_20250317.m4a 00:12:34]
- 서증으로 낼 때 번호가 정해져 있으면 서증 번호와 시각을 함께 쓴다. 예: [갑 제7호증 녹취록 00:12:34]
- 알아듣기 어렵거나 받아쓰기가 의심스러운 부분(앞뒤 문맥이 안 맞음, 같은 말이 반복됨)은 "원음 확인 필요"로 따로 모아 시각과 함께 보고한다. 추정해서 메우지 않는다.
- 발언자 구분(누가 말했는지)은 이 스크립트가 하지 않는다. 문맥으로 발언자를 추정해 적을 때는 "(추정)"을 붙인다.

## 다른 스킬에서 이 스킬을 부르는 방법

음성파일을 재료로 받는 스킬의 처리 절차 첫머리에 아래 한 줄을 넣으면 된다.

> 자료 중 녹음·동영상 파일(mp3, m4a, wav, mp4 등)이 있으면 먼저 `legal-transcribe` 스킬로 한꺼번에 변환하고, 생성된 `.녹취록.txt`를 재료로 쓴다.
